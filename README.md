# Automatic-Face-Analysis-for-3D-Avatar-Animation

## Setup
1. Install python3.9
2. create virtualenv
3. enter in virtualenv
4. install [freenect2](https://github.com/OpenKinect/libfreenect2) (During the procedure, a Makefile will be used. If certain components are not available, you need to modify it to remove the installation of the related drivers, as installing them may cause malfunctions.)
5. install requirements with `pip install -r requirements.txt`
